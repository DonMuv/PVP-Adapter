# PVP-Adapter
This is the official repository for the paper "PVP-Adapter: Dual-branch Spatial-frequency Adaptation for Change Detection of Photovoltaic Panels".

# Datasets
We provide the data for the [Germany](https://drive.google.com/file/d/1Ejx9_Ohjw2HPs6tH0DQ_W0PmksEXkmM3/view?usp=sharing) and [California](https://drive.google.com/file/d/1K6uzSii0zLSBFsjKvJYgBH_OVufp_24f/view?usp=sharing) test regions, the complete dataset will be publicly released in the near future.

# Getting Started
The training code will be public after the paper is formally accepted.
